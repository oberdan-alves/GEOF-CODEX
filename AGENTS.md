# Instruções permanentes — GEOF-CODEX

Estas regras se aplicam a todas as tarefas no repositório `oberdan-alves/GEOF-CODEX`.

1. Trabalhe sempre na branch `main`. Não crie nem utilize branches alternativas, como `work`, `codex/*` ou temporárias, salvo autorização expressa do usuário.
2. Antes de começar, confirme a branch e sincronize o repositório com o GitHub. Se restrições do ambiente, permissões ou políticas impedirem o trabalho direto na `main`, informe o impedimento antes de executar o trabalho.
3. Modifique diretamente os arquivos existentes correspondentes à solicitação, preservando as funcionalidades fora do escopo. Não crie arquivos alternativos para substituir os originais.
4. Após modificar o código, revise o diff, execute os testes disponíveis e confira se os arquivos alterados são os corretos.
5. As solicitações de alteração do usuário incluem autorização para fazer commit e publicar em `origin/main`, no repositório `https://github.com/oberdan-alves/GEOF-CODEX`, quando tecnicamente permitido.
6. Não considere um commit local como conclusão da publicação. Informe claramente se o envio ao GitHub foi efetivado e se as alterações estão na `main`.
7. Se houver bloqueio de autorização, explique qual autorização está faltando e aguarde confirmação. Não utilize outra branch como alternativa silenciosa.
8. No relatório final, informe os arquivos modificados, os testes executados, o identificador do commit e o resultado do envio para `main`.

Objetivo: realizar as alterações nos arquivos originais e publicá-las na `main`, sem exigir uma nova solicitação de publicação a cada tarefa.
